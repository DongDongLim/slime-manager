# slime-manager

SlimeAdventure 관리판: 기획서 열람, 일감 칸반, 버그 트래킹을 한 페이지에서 본다.

- 링크: https://dongdonglim.github.io/slime-manager/
- 이 저장소에는 페이지 코드만 있다. 기획서와 이슈는 실행 중에 각자의 GitHub 토큰으로 비공개 저장소에서 읽고, 브라우저 밖으로 저장하지 않는다.
- 처음 열면 [토큰 발급 안내](https://dongdonglim.github.io/slime-manager/guide.html)를 따라 토큰을 만들어 **설정**에 넣는다. 토큰은 그 브라우저의 localStorage 에만 남는다.
- 토큰이 없으면 예시 데이터로 열린다.

사용법과 라벨 규칙은 비공개 저장소의 `SlimeAdventure/manager/README.md` 를 따른다.
