토큰 발급 방법

저장소 주인 (Dong): 이 저장소에만 쓰는 fine-grained 토큰

  1. GitHub 토큰 만들기 화면을 엽니다.
  2. Token name 에 slime-manager, Expiration 은 원하는 기간을 고릅니다.
  3. Resource owner 는 DongDongLim, Repository access 는 Only select repositories → GameMaker.
  4. Permissions → Repository permissions 에서 Issues: Read and write, Contents: Read-only 로 바꿉니다.
  5. Generate token 을 누르고, 나온 토큰을 복사해 위 칸에 붙여 넣은 뒤 저장을 누릅니다.

협업자 (Wan): 남의 개인 저장소에는 fine-grained 토큰을 쓸 수 없어 classic 토큰을 씁니다.

  1. 먼저 Dong 이 저장소 Settings → Collaborators 에서 Wan 을 초대하고, Wan 이 초대를 수락합니다.
  2. classic 토큰 만들기 화면을 엽니다 (repo 권한이 미리 체크되어 있습니다).
  3. Expiration 을 고르고 Generate token → 복사해서 위 칸에 붙여 넣고 저장.

토큰은 비밀번호와 같습니다. 다른 사람에게 보내거나 공용 PC 에 저장하지 마세요. classic 토큰은 Wan 이 접근할 수 있는 모든 저장소에 쓸 수 있으니 만료 기간을 짧게 두세요.
